# «Голубое Озеро» — сайт с ценами в одном файле

Откройте `index.html` в браузере. В папке должны оставаться `styles.css`, `prices.js` и `assets/`.

## Как поменять цену

1. Откройте `prices.js` любым редактором, например VS Code.
2. В начале файла найдите нужную позицию, например `standard: 4000,`.
3. Измените её на `standard: 4500,` и сохраните файл.
4. Обновите страницу в браузере (при необходимости `Ctrl+F5`).

Менять HTML для обновления цен **не нужно**: атрибуты `data-price` привязаны к именам в `prices.js`.

### Где находятся тарифы

- `gazebos` — беседки и веранда; аренда 08:00–22:00.
- `cabins` — домики и доплаты за сутки.
- `hotTub` — банный чан и дополнительные опции.
- `camping` — цены и доплаты за сутки.
- `rentals` — катамаран, сап-борд за час и шезлонг за день.

Числа вводятся **без пробелов** и знака рубля: `4500`, а не `4 500 ₽`.

В HTML связь выглядит так:

```html
<strong data-price="gazebos.standard">…</strong>
```

При загрузке `prices.js` заполнит этот элемент строкой `4 000 ₽` (или новым значением).
Для доплат используются `data-price-prefix="+"` и `data-price-suffix="/сутки"`.

**Важно:** теперь для отображения тарифов включён JavaScript. Без него на странице вместо числовой цены будет многоточие. Остальная часть сайта и видео работают как раньше. Для поисковой индексации цен и при переходе на Astro лучше подставлять их на этапе сборки страниц.

Для будущих оплат Java/Spring Boot должен получать и проверять реальные цены на сервере: значения JavaScript в браузере нельзя считать защищёнными.
